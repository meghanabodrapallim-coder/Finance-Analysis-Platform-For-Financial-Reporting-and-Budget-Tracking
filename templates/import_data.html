📋 File Format Guide


Your file should have these columns (column names are flexible):

Required Column:

Optional Columns:

Example CSV format:
date,category,description,amount,type
2026-07-01,Food,Lunch,250,Expense
2026-07-02,Travel,Bus fare,50,Expense
2026-07-03,Salary,Monthly pay,45000,Income

💡 Tip: The system automatically detects your columns even if they have different names. Just make sure you have an amount/price column!
