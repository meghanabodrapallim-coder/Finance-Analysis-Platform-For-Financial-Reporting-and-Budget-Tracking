# Finance Analysis Platform For Financial Reporting and Budget Tracking

A complete AI-assisted personal finance management platform built with Python and Flask — covering expense tracking, budgeting, investments, goal planning, portfolio analytics, and a conversational AI assistant (JARVIS).

**Live Demo:** https://smart-finance-insights-dvjw.onrender.com

## Features
- Expense, budget, and income tracking
- Investment portfolio and goal management with AI-suggested savings
- Portfolio analytics and spending personality insights
- JARVIS — a natural-language financial assistant
- Multi-format report export (CSV, Excel, Word, PDF)
- Secure authentication with hashed passwords
- Automated testing with pytest
